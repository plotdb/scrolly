@plotdb/scrolly

A tiny scrollytelling engine — Scrolly.init() wires steps to sticky scenes over a data-scene contract. Scroll to see it switch. Charts drawn with the bundled Scrolly.chart d3 helpers.

Scene · line

A line, drawing itself in

Each .step carries a data-scene. As it reaches mid-viewport, the engine shows the matching .scene and calls your onStep.

data-phase="peak"

Same scene, different phase

Several steps can share one scene and pass a data-phase to request a variant — here, annotating the peak.

Scene · bar

Switch to another visual

A different data-scene swaps the sticky graphic entirely. Any chart works — the engine only cares about the markup contract.
